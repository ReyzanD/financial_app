   → Shows what data is available

C) Loading State:
   ⏳ [LocationRecommendations] Loading...
   → Shows loading in progress

D) Empty State:
   ℹ️ [LocationRecommendations] No recommendations available
   → Shows no data returned

E) Success State:
   ✅ [LocationRecommendations] Showing 3 recommendations
   → Shows data is there!

F) Error State:
   ❌ [LocationRecommendations] Error: [error message]
   ❌ Stack trace: [trace]
   → Shows what went wrong
